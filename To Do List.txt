Now let's get you a Google Places API key. This is a one-time setup on your Google account — no coding involved on your end, just clicking through their console.

1
Create a Google Cloud project
Go to console.cloud.google.com in your browser and sign in with any Google account. If asked, agree to the terms. Click the project dropdown near the top-left and choose 'New Project'. Name it something like 'Selected Sports' and click Create.
2
Enable billing on the project
Google requires a billing account on file before it will issue API keys, even though your usage will almost certainly stay within the free monthly credit ($200/month, and ground searches use only a tiny fraction of that). In the left menu, go to Billing, then 'Link a billing account', and add a card. You will not be charged unless usage far exceeds the free tier, which is very unlikely for this app.
3
Enable the Places API and Maps JavaScript API
In the search bar at the top, type 'Places API' and open it, then click Enable. Do the same search for 'Maps JavaScript API' and enable that too — we need both: one for ground search/autocomplete, one for showing results.
4
Create an API key
In the left menu go to APIs & Services > Credentials. Click '+ Create Credentials' at the top, choose 'API key'. Google will generate a long key starting with something like AIza... Copy this key somewhere safe — you'll paste it back here for me to wire in.
5
Restrict the key to your website
Click on the API key you just created to edit it. Under 'Application restrictions', choose 'Websites' and add https://selectedsports.github.io/* as an allowed referrer. This stops anyone else from using your key if they find it in the site's public code. Save.
